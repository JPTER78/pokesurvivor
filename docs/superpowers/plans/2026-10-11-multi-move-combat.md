# Multi-move Combat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every attack move the Pokémon knows fires on its own cooldown (up to 6) with 4 passive slots, plus fusion moves bought with legendary bonds and automatic elemental reactions, with enemy HP scaled to the number of attacks held.

**Architecture:** `combat.js` becomes an orchestrator (per-move aiming, one `damage()` entry point, projectile resolution) and the 14 move kinds move to `move-kinds.js`. New data files hold passives, fusions and reactions; `Player` keeps `moves`, `passives` and `focus`. A node test runner (`tools/test.js`) loads the data and logic files in a vm sandbox, the same trick `tools/export_data.js` already uses.

**Tech Stack:** Vanilla JS (ES2020) on Canvas 2D, no build for dev (`dev.html` loads each script); `node tools/build.js` bundles with terser into `js/app.min.js` + `index.html`. Node 26 for tests and build. Python 3 regenerates the static SEO pages.

**Spec:** `docs/superpowers/specs/2026-10-11-multi-move-combat-design.md`

## Global Constraints

- The game is written in Spanish; every new player-facing Spanish string gets an English entry in `js/data/lang-en.js` (key = exact Spanish text, `{x}` for holes).
- No emojis anywhere; icons come from `G.Icons` (`js/ui/icons.js`).
- Edit `dev.html`, never `index.html` (generated by `node tools/build.js`).
- Scripts are plain IIFEs on the global `G`; a new file must be added to the `<!-- scripts:begin -->` block of `dev.html` in dependency order.
- Grep with `--include=*.js` and exclude `js/app.min.js` (a 900 KB bundle) or the output floods the terminal.
- Numbers from the spec: `MAX_MOVES = 6`, `MAX_PASSIVES = 4`, `FOCUS_MUL = 1.25`, melee/dash base damage ×1.4, enemy `powerK = 1 + 0.4 × (attacks − 1)`, boss `1 + 0.3 × (attacks − 1)`, wet 2.5 s, frozen 1.2 s, reaction cooldown 0.5 s per enemy, shot sfx throttle 80 ms, water types in water ×1.15 speed / +1 HP/s / ×1.15 damage taken, flying types hover with ×1.1 cooldowns.
- Commit messages in Spanish (repo convention), ending with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
- Run `node tools/test.js` before every commit.

## Review Focus

Inputs the spec implies but that need a pinned test (each is added to the owning task):

1. **A Pokémon whose pool has fewer than 6 attack moves** (e.g. a pure Normal type: 5 attacks after the buff moves go). Level-up must stop offering "new move" cards and still fill 3 cards. → Task 6 test `offer never returns fewer than 3 cards when the pool is exhausted`.
2. **Fusing when the focused move is one of the sources.** `focus` must point at the fusion afterwards and never at an index past `moves.length`. → Task 8 test `fuse keeps focus valid`.
3. **A coop puppet state string from an older client** (single id, no `:`) or garbage. Puppet keeps its last move list and does not throw. → Task 12 test `parseMoves tolerates garbage`.
4. **Reactions on a remote enemy in a guest** with no status bits. Must never trigger. → Task 9 test `no reaction on remote enemy without bits`.
5. **Power scaling with a dead or remote player with no moves** (`moves` empty). `powerK` must treat them as 1 attack, never divide by zero. → Task 10 test `powerK ignores empty move lists`.

/* ============ combat.js — recargas, apuntado, daño y colisiones ============
 * TODOS los movimientos del jugador se lanzan a la vez, cada uno con su
 * recarga y su propio objetivo (aimFor). El cómo de cada familia está en
 * systems/move-kinds.js. Todo el daño del jugador a un enemigo pasa por
 * damage(): tabla de tipos, clima, enfoque, estados y (systems/reactions.js)
 * reacciones elementales.
 *
 * Cooperativo: cada ordenador ejecuta los ataques de SU jugador. Los de los
 * compañeros llegan por la red y se repiten como "fantasma" (ghostCast): se
 * ven igual, pero no hacen daño aquí (ya lo hizo su dueño).
 */
G.Combat = (() => {
  const MK = () => G.MoveKinds;

  // ---------------- apuntado ----------------

  /**
   * Objetivo y ángulo de UN movimiento. A distancia: el jefe si está a tiro >
   * lo que te toca > el más cercano. Cuerpo a cuerpo y el resto: lo que te toca
   * > el jefe > el más cercano. Sin enemigos, la roca o cofre más cercano;
   * sin nada, hacia donde caminas (o donde ya mirabas).
   * Guarda m.target y m.aim y los devuelve.
   */
  function aimFor(pl, m, all) {
    const ranged = MK().isRanged(m.kind);
    const threat = G.Projectiles.nearest(all, pl.x, pl.y, pl.r + 24);
    const boss = all.find(e => e.boss && !e.dead && G.U.dist(pl.x, pl.y, e.x, e.y) < 330) || null;
    const tg = (ranged ? boss || threat : threat || boss)
            || G.Projectiles.nearest(all, pl.x, pl.y, 520)
            || G.World.nearestBreakable(pl.x, pl.y, 200)
            || null;
    m.target = tg;
    m.aim = tg ? Math.atan2(tg.y - pl.y, tg.x - pl.x) : pl.walking ? pl.moveAngle : pl.aim;
    return { target: tg, aim: m.aim };
  }

  // ---------------- lanzar ----------------

  function tick(dt, pl, now) {
    if (pl.dead) return;
    const all = G.EnemyMgr.all();
    for (const m of pl.moves) tickMove(dt, pl, m, now, all);
  }

  function tickMove(dt, pl, m, now, all) {
    if (m.kind === 'orbit') { MK().orbit(pl, m, dt, now); return; }
    m.t -= dt;
    if (m.t > 0) return;
    aimFor(pl, m, all);
    // Los que necesitan blanco esperan a tenerlo a su alcance (no gastes animación al aire).
    if (MK().needsTarget(m.kind) && !(m.target && G.U.dist(pl.x, pl.y, m.target.x, m.target.y) <= MK().reach(m))) {
      m.t = 0.05;
      return;
    }
    m.t = Math.max(0.05, m.cd * pl.cdK);
    pl.cast(m);
    if (G.Coop.active) G.Coop.cast(pl, m);
    m.castAt = performance.now();   // destello en el HUD
    MK().run(pl, m, false);
  }

    if (e.remote) return !!(e.net && (e.net.st & BIT[status]));
    if (status === 'burn') return e.burn > 0;
    if (status === 'poison') return e.poison > 0;
    if (status === 'slow') return e.slow > 0;
    if (status === 'wet') return e.wet > 0;
