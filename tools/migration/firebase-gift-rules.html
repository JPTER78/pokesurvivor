Esta página solo te ayuda a copiar las reglas de migración y regalos desde el navegador del teléfono. No tiene acceso a tu cuenta de Firebase ni cambia el servidor por sí sola.

Comprueba primero: estás en pokesurvivor-tiliko y ya hiciste un respaldo de las reglas actuales. Nunca publiques estas reglas en pokesurvivor-free (el original).

Copiar el archivo completo

El botón carga el archivo firestore.rules incluido en esta misma versión del repositorio y lo coloca en el portapapeles. No se necesitan permisos de cuenta ni instalar nada.

Publicar en Firebase Console

  1. Abre la pestaña Firestore Database → Reglas del proyecto pokesurvivor-tiliko.
  2. Pega el contenido completo sustituyendo solo las reglas existentes.
  3. Revisa que no haya errores de sintaxis y usa Publicar únicamente después de confirmar que las pruebas del emulador terminaron correctamente.
  4. El código público MAO25 funciona para cada cuenta una vez; no necesitas crear migrationGrants para canjear regalos. Esa colección solo se utiliza para migraciones manuales autorizadas.
