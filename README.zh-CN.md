# PokéSurvivor 简体中文版

与宝可梦伙伴一起躲避围攻、学习招式、挑战裂缝，并收集异色宝可梦。
目前收录 966 只宝可梦，支持最多 4 人在线合作。

首次访问沿用原版规则：西语浏览器使用西语，其余浏览器使用英语。访问 `/zh/` 或在“设置 → 画面 → 语言”中选择“简体中文”即可使用中文。
游戏会记住选择，切换后重新加载。名称沿用官方简体中文；招式及道具的效果以本作机制为准。

## 本地运行

直接打开 `index.html`，或运行本地预览：

```powershell
node tools/preview.js
```

然后访问 `http://127.0.0.1:8765/`。此预览使用本地账号和本地存档，适合体验及校对。
中文攻略和图鉴位于 `/zh/guide/`、`/zh/pokedex/`，其他玩家页面可从导航栏访问。
字体、术语和游戏数据均随项目提供，游玩时无需下载翻译数据或字体。

本地账号的存档位于当前浏览器；访客模式不保存进度。清除浏览器的网站数据会删除本地存档。
原项目的云端账号、跨设备同步及合作模式继续使用既有网络服务。

## 翻译及构建

修改 `dev.html` 和源码文件；入口 HTML、压缩脚本及玩家页面由以下流程生成：

```powershell
node tools/build.js
node tools/export_data.js
python tools/make_seo_pages.py
```

术语来源、字体生成和测试方式见 [中文化维护说明](docs/LOCALIZATION.md)。
